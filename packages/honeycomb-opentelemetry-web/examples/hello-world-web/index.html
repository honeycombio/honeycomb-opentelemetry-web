Things to try

  • Watch it roll over on its own. Leave the page alone. With no telemetry, the session expires one inactivity timeout after the last read and a new id appears in the log.
  • Keep it alive, then watch max duration win. Click Start heartbeat. A span every few seconds keeps resetting the inactivity timer, so the session survives until it hits the max duration and rolls over anyway.
  • See persistence. Reload the page. The same id comes back out of localStorage — a session outlives the page load. Reload after the max duration has passed and you get a new one, because the stored session records its start time.
  • Start from scratch. Clear stored session then reload: a brand new id is minted.

"Activity" means emitted telemetry, not mouse movement: the inactivity timer only resets when a span or log record reads the session id, and SessionManager ignores reads within 5 seconds of the previous one. Clicking a button here does count, because user-interaction instrumentation turns the click into a span.
